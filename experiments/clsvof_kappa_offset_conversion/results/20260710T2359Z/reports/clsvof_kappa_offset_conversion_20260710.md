# CLSVOF 曲率位置转换验证（2026-07-10）

## 结论

`nn_offset_d` 的二维平行曲线公式在解析离线矩阵中通过，capwave 的完整保持门也通过；但 rising case2/N512 未通过完整保持门，且真实动态 CLSVOF 单元相对 native FD 的局部误差不是一致改善。因此本轮结论为 **diagnostic-only**：不替换现有 `nn_direct` 部署路径，也不声称 solver-level 收益。

公式：`q_d=q_Gamma/(1+(d/Delta)q_Gamma)`，`kappa_d=q_d/Delta`。`offset_grad` 未达到相对 `offset_d` 额外改善 5% 的选择阈值，故未进入完整 CFD。

## 审计边界

所有试验均为独立 overlay；`basilisk/src` 未改写。直接路径复用的是本轮带动态 probe 的同源码、模型、raw27 和导出头文件 hash 运行；probe 宏仅记录诊断，不修改 solver 状态，且每个 run 的编译参数完整记录在 manifest。
