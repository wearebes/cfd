# Native-only retained evidence

The former `clsvof_nn` rows in this matrix used the obsolete direct
`q_gamma/Delta` deployment path. They and every derived comparison table,
figure, PDF, source-data export, aggregate, audit verdict, scheduler record,
and verification bundle were deleted.

Only the 48 native CLSVOF row directories are retained. This directory is not
a completed matrix and supports no NN-versus-native conclusion.

Future NN rows must use the existing `clsvof_kappa_offset_conversion`
deployment contract:

`q_cell = q_gamma/(1 + (d/Delta)*q_gamma)`, followed by
`kappa_cell = q_cell/Delta`.
